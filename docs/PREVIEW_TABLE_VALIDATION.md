# Preview gestures and table validation

The combined Windows release runs generated-data checks for zoom focal-point
preservation, Fit/zoom limits, blank pixels, unknown metadata presentation,
zero exposure and import of bias/master bias filenames and FITS headers.
WPF smoke checks cover numeric exposure sorting, reversal, sorting after refresh,
Shift-column priority, performance sorting, bias/dash/target bindings and
single-file preview menu availability. The viewer uses the existing colour
preview decoders and adds pinch/wheel zoom and drag-to-pan without editing pixels.
Touch and trackpad behaviour still needs verification on physical Windows hardware.
