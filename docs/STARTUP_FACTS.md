# Celestial-object facts in the loading window

The 20 additional facts in `Application_Source/StartupMessages.cs` are concise,
original summaries of these NASA and NASA/JPL references. They are bundled
offline; the loading window does not fetch these sources during startup.

| Object | Fact covered | Reference |
| --- | --- | --- |
| Crab Nebula (M1) | Supernova recorded in 1054 | [NASA: Messier 1](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-1/) |
| Ring Nebula (M57) | Football-shaped gas structure inside a doughnut-shaped ring | [NASA: Messier 57](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-57/) |
| Dumbbell Nebula (M27) | First planetary nebula discovered, in 1764 | [NASA: Messier 27](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-27/) |
| Veil Nebula | Remains of an exploded massive star | [NASA: Veil Nebula](https://science.nasa.gov/missions/hubble/veil-nebula-supernova-remnant/) |
| Eagle Nebula | Star formation in the Pillars of Creation | [NASA: Eagle Nebula](https://www.nasa.gov/image-article/eagle-nebula-2/) |
| Horsehead Nebula | Dark cloud against glowing background gas | [NASA/JPL: Horsehead Nebula](https://www.jpl.nasa.gov/images/pia04215-horsehead-nebula/) |
| Whirlpool Galaxy (M51) | Galaxy interaction and star formation | [NASA: Messier 51](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-51/) |
| Sombrero Galaxy (M104) | Bright central bulge and dark dust lane | [NASA: Messier 104](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-104/) |
| Hercules Cluster (M13) | Hundreds of thousands of stars in a globular cluster | [NASA: Messier 13](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-13/) |
| Omega Centauri | Millions of stars appearing as a single fuzzy object | [NASA/JPL: Omega Centauri](https://www.jpl.nasa.gov/images/pia13125-omega-centauri/) |
| Cigar Galaxy (M82) | Starburst activity associated with M81 | [NASA: Messier 82](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-82/) |
| Triangulum Galaxy (M33) | Third-largest galaxy in the Local Group | [NASA: Messier 33](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-33/) |
| Sirius | Earth-sized white dwarf companion | [NASA: Sirius and its companion](https://science.nasa.gov/asset/hubble/the-dog-star-sirius-and-its-tiny-companion/) |
| Polaris | Triple-star system with a variable supergiant | [NASA: Polaris system](https://science.nasa.gov/asset/hubble/artists-concept-of-polaris-system-annotated/) |
| Betelgeuse | Red supergiant larger than Mars's orbit | [NASA: What is Betelgeuse?](https://science.nasa.gov/universe/what-is-betelgeuse-inside-the-strange-volatile-star/) |
| Double Cluster | Open clusters NGC 869 and NGC 884 | [NASA/JPL: Double Cluster](https://nightsky.jpl.nasa.gov/news/167/) |
| Jupiter | Roughly ten-hour rotation, shortest planetary day | [NASA: Jupiter facts](https://science.nasa.gov/jupiter/jupiter-facts/) |
| Saturn | Rings composed predominantly of water ice | [NASA: Cassini ring science](https://science.nasa.gov/mission/cassini/science/rings/) |
| Venus | Rotation takes longer than an orbit around the Sun | [NASA: Venus facts](https://science.nasa.gov/venus/venus-facts/) |
| Uranus | Axial tilt of about 98 degrees | [NASA: Uranus facts](https://science.nasa.gov/uranus/facts/) |

For Venus, the fact explicitly describes one rotation relative to the stars.
Its sunrise-to-sunrise solar day is shorter, so the loading text avoids the
ambiguous claim that every definition of a Venusian day is longer than its year.
