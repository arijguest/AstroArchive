AstroArchive 1.13.13
Package 1.13.13.1

- Target identification solves one representative per selected Light session,
  target and compatible instrument group, updating the selected group together.
  Stacks are solved individually; batch review offers each target after solving.
- The nearest major target in the solved field is selected automatically, including
  when several major targets are nearby. Review allows individual overrides or
  leaving a group unchanged. Fields without major candidates require a choice.
- Solved positions use the image centre, with the WCS footprint when available.
  Group updates retain individual capture times and existing pointings. IDs and
  common names continue to share one target identity.
- A single progress window shows job counts, representative filename, group scope,
  solver stage, elapsed time and time limits. The repeated solve/save dialog cycle
  and per-subframe star-matching reads have been removed.
- Progress windows open without stealing focus and detach before closing, keeping
  the main window's state intact. Error messages appear after progress has closed.
- Cancellation terminates unresponsive local solver processes. Local and online
  solving have five- and ten-minute deadlines; failed fields do not stop the batch.
- Unknown Common name values display as a dash in Repository, Import and Edited.
