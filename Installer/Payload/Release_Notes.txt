AstroArchive 2.1.13
Package 2.1.13.1

- Table headings now use ID, OBJECT, TYPE and DATE. File receives the largest
  default width preference; columns adapt to window and preview-pane resizing.
  Manual dragging still redistributes neighbouring widths and allows horizontal
  scrolling. Restoring default columns also restores their default widths.
- Responsive widths respect physical pixel rounding to avoid scrollbar resize
  loops. Recycled headers show the current sort direction and priority.
- Up and Down navigation on grouped subs changes the selected group and its
  files, keeping selection and keyboard focus together.
- Grouped exposure labels show durations such as 10s and use total for the
  accumulated exposure, retaining mixed and unknown exposure indicators.
- Target rows omit a repeated catalogue ID after the common name, including
  IC434 - Flame Nebula, while preserving distinct catalogue identities.
