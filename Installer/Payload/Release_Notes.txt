AstroArchive 2.1.10
Package 2.1.10.1

- Replaced the Activity bell with a cleaner outline icon. Its button matches
  the toolbar's height, alignment, spacing and colours. Notification indicators
  no longer change its width; the icon follows the selected text size.
- Escape clears all file selections on the active Repository, Edited or Import
  page, including selections under other targets and condensed sessions. It
  works from the search bar and target pane as well as the file table. Open
  menus, dropdowns and Activity still dismiss before clearing file selections.
- Verified that importing a recognised Seestar stack keeps it in Repository;
  Edited working copies are created only through an explicit Edited action.
