AstroArchive 1.13.10
Package 1.13.10.1

- Shorter tooltips throughout menus, previews, filters and metadata controls.
  Essential selection rules, deletion effects and capture evidence remain available.
- Faster repeat telescope imports skip archived filenames and completed dated
  DWARF sessions by default. Seestar imports still discover new filenames.
  Robust import matching checks changed files, metadata and missing archive copies;
  Full rescan revisits everything. Newly imported copies remain checksum-verified.
- A visible Import from telescope button uses saved connected-device profiles.
- Exports default to images without metadata or an enclosing folder. Stacks copy
  directly to the destination; subs retain compatible input folders. Add Metadata
  and Create new folder are separate options, both off by default.
- Existing export files are retained with numbered filename suffixes. Cancelled
  exports keep verified copies and remove unfinished temporary files.
- Stacking-app buttons work with metadata-free exports.
- Shorter offline guides describe the current app, with licensing and catalogue
  credits retained.
