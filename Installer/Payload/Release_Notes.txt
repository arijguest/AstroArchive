AstroArchive 3.1.7
Package 3.1.7.1

- Fix updates leaving AstroArchive unable to open when Windows Smart App Control
  or SmartScreen blocks the new version's Start.exe, as happened with 3.1.6.
  After every install or update, setup checks that Windows will start the
  launcher and app. If Windows blocks them, AstroArchive automatically returns
  to the newest earlier installed version that starts, repoints its shortcuts,
  and explains what happened. The blocked package is not offered again.
- Installations stuck on a blocked 3.1.6: run this installer once. If Windows
  also blocks 3.1.7, setup restores your earlier working version instead.
- If Windows blocks the app itself, the launcher also restores the previous
  working version. Repositories, images and settings are never changed.
- Release checks now simulate a blocked update and fail if Windows Code Integrity
  rejects any installed executable.
- Includes the 3.1.6 changes: wider maximized Repository preview, centered
  Analytics metrics with corrected stack exposure totals, broader
  calibration-frame detection and opt-in sanitized error reports.
