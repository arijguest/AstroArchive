AstroArchive 1.7.0 — metadata-first mosaic collections
Package 1.7.0.1

- Preserve mosaic/project and panel hints during existing FITS/session reads.
  Explicit capture metadata is declared; missing/conflicting panel data stays
  available for review. Normal import detection never invokes a plate solver.
- Browse named collections and stable panels across targets, nights and filters.
  Assign captures manually, confirm suggestions, retain removed-member decisions,
  and attach completed stitched images separately from their contributing inputs.
- Reuse supported existing WCS to suggest adjacent fields and display footprints.
  Dithering and target-centre coordinates do not establish mosaic intent.
  Optional representative solving reuses caches; approximate outlines are labelled.
- Preserve collections in the portable index and a versioned hash/path manifest.
  Reindexing reconnects captures after index loss. Image paths and bytes stay intact.
- Export separate stacking inputs per panel and compatible capture group, keeping
  calibrations, cameras, filters and completed outputs separate. Review unresolved
  memberships before stacking. Stitch panel results in your external software.

Generated-data and native Windows checks cover detection, uncertainty, portable
recovery, panel export separation, collection controls and light/dark UI rendering.
Real telescope mosaic metadata and authenticated solver responses need validation
against the device firmware/provider in use.

AstroArchive 1.6.2 — failed filename cleanup and import exclusions
Package 1.6.2.1

- Repository tools > Delete failed searches all indexed captures for filenames
  containing "failed", regardless of case or current filters/telescope selection.
  Review and confirm the matching files before deleting repository copies.
  Originals and shared metadata stay; deletion history prevents reimport.
- Import options > Ignore failed saves a filename exclusion for folder imports,
  USB auto uploads and Dump processing. Matching FITS, including .gz variants,
  are skipped before reading their image data. Ignored originals are retained.
- Scan/import summaries report the number of ignored filenames. Rescan after
  changing the option. It is off by default and matches filename text, not
  folder names, target labels or failure statuses.

Download AstroArchive1.6.2.1.exe. Windows validation covers application regressions,
installer/update tests, native cleanup, installation/restart and WPF smoke checks.

AstroArchive 1.6.1 — processing handoffs, Dump inbox and preview refinements
Package 1.6.1.1

Combines the completed changes across the development chats since 1.6.0.1.

- Send a single uncompressed FITS stack directly to the verified 7 October
  AstroWizard build or Siril, using a verified working copy outside the archive.
  Direct incoming handoff to StackingWizard remains unavailable; use the existing
  ready-to-stack export folders for individual subs.
- Sort supported FITS from each archive's Dump folder when the archive opens.
  Remove successfully verified inputs and duplicates; retain failed, changed,
  unsupported or locked files. Settings includes open and retry controls.
  Existing deletion-history exclusions continue to prevent unwanted reimports.
- Compensate Auto/Strong previews for IRCUT/LP filters and severe colour casts.
  Display identified solar, lunar and planetary images without stretching.
  Source pixels and headers remain unchanged.
- Merge Sun and Solar into one Sun target during import and archive opening.
  Preserve existing indexed file paths and normalise cached and deleted labels.
- Give setup and Install release dialogues larger starting sizes, wrapping copy,
  spaced action buttons and a scrollable setup body for smaller screens.

Download AstroArchive1.6.1.1.exe. Windows validation covers application regressions,
installer/update tests, native cleanup, installation/restart and WPF smoke checks.
Physical telescope USB, touchscreen gestures and live cloud transfers still need
validation with real hardware and accounts.
