AstroArchive 2.1.3
Package 2.1.3.1

- Repository > Back up archive… opens the backup dialog directly.
- Settings > Backups provides a visible Preferences section for creating backups,
  restoration instructions and optional originals protection. These controls are
  no longer hidden in the collapsed General > Archive safety panel.
- Backup destinations and lossless ZIP choices remain available in the backup
  dialog. Existing backup settings, verified copies and image data are retained.
- Windows checks exercise both actual menu paths in light/dark themes and at
  100/150% text, including cancellation and unavailable/busy states.
