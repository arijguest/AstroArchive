AstroArchive 3.1.1
Package 3.1.1.1

- Live import keeps Connect over network available. Reconnect to choose more
  captures and download them while the live watcher continues.
- Import from multiple telescopes simultaneously. Each network session keeps its
  own progress, telescope identity and stop control in Activity. Use a separate
  saved telescope name for each physical device.
- A Live import underway indicator beside the connection button opens Activity
  and shows when multiple watchers are running. Stop live import or Cancel
  download affects only that session; Stop all telescope imports stops them all.
- Different telescope caches download in parallel. Overlapping requests sharing
  a cache wait safely and can be canceled independently. Archive scans and commits
  coordinate against the latest index so live/manual overlaps store a capture
  once, report duplicates correctly and reuse verified local downloads.
- Stopping imports or closing AstroArchive retains completed archive copies and
  verified downloads. Telescope originals remain unchanged. The archive closes
  after active sessions stop; conflicting archive operations wait until then.
