AstroArchive 2.1.8
Package 2.1.8.1

- Fixed interface verification overwriting the installed application's settings,
  which could clear the saved repository selection and make an intact archive
  appear empty. Test settings, backups and working indexes now use isolated state
  in the test output folder; they cannot replace the installed user's settings.
- Added a regression check that verifies isolated settings writes, backups and
  repository indexes before running the interface checks.
- Removed duplicate calls to the UX verification suite.
- Existing repository databases, image files and metadata are retained. If a
  previous interface check cleared your repository selection, choose the existing
  archive in Settings > General > Choose repository; no reimport is required.
