AstroArchive 3.1.5
Package 3.1.5.1

- Repository > Analytics opens directly into the Analytics workspace. Clear
  Document and Video / GIF controls group the available export formats.
- Customize each chart's title, subtitle and palette with a live preview. Choose
  supported chart styles, category ordering and density; save configurations for
  future sessions or reset to defaults. Repository headline totals remain complete.
- Set a custom total video length alongside the existing pacing presets. Chart
  reveals and Glide, Zoom or Dissolve transitions adapt to the available reading
  time. MP4 stories finish cleanly; GIF stories loop smoothly into their first chart.
- Refined social layouts use larger focal charts, more compact headers and fuller
  plot areas. PNG, JPEG, PDF, SVG, MP4 and GIF share the customized chart styling.
- The Repository preview opens narrower, giving the skymap more space. Its reset
  control scales with the globe and stays anchored through resizing, rotation,
  zooming and refresh, in both themes and at different display scales.
- Removed verified unused code and stale generated installer payload copies.
  Installer builds package fresh application files; existing features are retained.
