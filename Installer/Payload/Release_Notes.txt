AstroArchive 2.1.14
Package 2.1.14.1

- Target and All targets exposure totals include video duration for AVI, MP4,
  MOV, M4V, WMV, MKV and SER recordings. Video-only targets show their totals;
  missing durations remain marked as unknown. Videos retain their Video type.
- Metadata menus apply changes to every selected file by default in Repository,
  Import and Edited, including selections spanning targets or Edited projects.
  Editors clearly show the batch scope and preserve unchanged fields. Expanding
  changes to entire capture sessions remains an optional choice.
- Clicking a Repository or Edited row without Ctrl or Shift selects only that
  entry and clears earlier selections, including files hidden under other
  targets. Plain grouped-sub selection also replaces the previous batch.
  Right-clicking an already selected entry preserves the batch for file actions.
