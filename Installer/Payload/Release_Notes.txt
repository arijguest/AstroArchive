AstroArchive 1.12.0
Package 1.12.0.1

- Repository uses expandable subframe session summaries with dates, file count,
  exposure and filters. Show all files restores a flat view; stacks stay separate.
- Edited has targets, a compact table and Preview, with All projects browsing,
  saved column layouts and numeric exposure sorting.
- Edited folder imports offer Browse, Scan and review, skipping repository/database
  folders and archived originals, including renamed identical copies.
- GIFs match uniquely named edited images and retain available acquisition details.
  GIF and SER playback has Pause / Play; common videos use Windows codecs.
- Preview shows original capture filenames. Moon and Lunar share the Moon target.
- Dump processing has a cancellable progress window. Import buttons have more
  space below them.

Stacking and editing use external software. Video playback depends on installed
Windows codecs; unknown acquisition data remains unknown.
