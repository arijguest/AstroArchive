AstroArchive 3.3.3 — direct website distribution
Package 3.3.3.1

Includes the locally preserved upgrades through 3.3.2.2, following 3.1.9.1:
- Network telescope imports, verified transfers and recovery.
- Hybrid/offline choice and bundled target information, orbital and sky data.
- Faster long imports, responsive list refresh and retained selection.
- Resumable verified backups, updated date/time sorts and export menus.
- Sky-map corona, Sun/Totality classification and upcoming sky events.
- Telescope management, updated guides and seven interface languages.

This release changes downloads, release notes and update checks to the AstroArchive
website. Downloads retain SHA-256, byte-size and version checks. Diagnostic reports
open the website support form for review; they are never submitted automatically.

One-time migration: existing 3.1.9.1 and other GitHub-based installations must run
this website installer manually once. They cannot discover this new feed using
their old updater. Subsequent website builds use /update.json on the website.

This local build is unsigned. All original captures and repository data remain
outside application installation files.
