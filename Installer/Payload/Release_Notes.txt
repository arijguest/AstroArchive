AstroArchive application 1.2.0 — installer package 1.2.0.2

The installed launcher checks the latest stable GitHub release at startup.
When an update is available, it asks whether to install with Yes selected by
default. No opens the installed version. Accepted downloads are checked for
exact size and SHA-256, then installed in place and AstroArchive is restarted.
Offline or failed checks keep the current app usable. --no-updates skips checks;
--updates performs a manual check and shows its result.

Existing original offline installations need this installer once to gain the
new launcher. Repositories, images, import manifests, caches and settings are
retained. Manual installation, repair and uninstall remain available offline.

The application remains version 1.2.0. Windows CI builds the application from
source and validates application, installer, updater and Windows smoke checks
before publishing installers and the update feed. The package is unsigned.
