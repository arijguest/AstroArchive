AstroArchive 1.13.15
Package 1.13.15.1

- C23, NGC891, UGC1831, PGC9031, Silver Sliver Galaxy and Outer Limits Galaxy
  resolve to one target, with the common name displayed across the programme.
- Expanded established common-name coverage, including Skull, Blue Snowball,
  Silver Needle, Little Sombrero, Splinter and Hubble's Variable Nebula.
- Common names, catalogue prefixes, accents and punctuation share one matching
  method. Explicitly conflicting IDs, including unknown IDs, are not ignored.
  Catalogue numbers are never corrected using fuzzy name matching.
- Right-click a target on Repository or Edited to edit its common name and aliases.
  Saved names take effect immediately in existing entries, imports, searches,
  target choices and Edited fuzzy matching. Conflicting aliases are rejected;
  catalogue identities and image files stay unchanged.
- Whole-region names such as Eagle, Flame, Rosette and Eastern Veil have declared
  owners. Shared component names include their IDs. Ambiguous names such as
  Antennae Galaxies and Lobster Nebula require an ID rather than an automatic guess.
- Both Targets panels are wider. Long names and alternate catalogue IDs wrap
  fully instead of being truncated, including at larger text sizes.
- Catalogue audits test every supplementary name and alias, all display names,
  numeric-ID ownership, existing archives and real telescope import grouping.
