AstroArchive 1.5.0 — import performance and continuous ETA
Package 1.5.0.1

Progress and elapsed timers start before metadata processing. Copy progress and
ETA now advance inside the first large file and during destination verification.
Recent throughput and measured copy/verification costs drive estimates; prior
timings seed provisional estimates. Provider stalls, optional cleanup and final
index/manifest work are shown explicitly. Project and selected-file exports share these timers.

Discovery continues while bounded metadata workers inspect files. A local spill
inventory avoids delaying scan totals behind cloud reads. Shared session JSON is
read once per scan, filename target matching is indexed and live frame snapshots
avoid JSON serialization. Trusted unchanged FITS headers can be reused on a
rescan before import; current session metadata and user overrides are reapplied.

Copy/hash buffers are reused, duplicate checks use indexed archive lookups,
unchanged verified snapshots are skipped, and worker tuning uses smaller
size-spread samples and stops escalation when throughput stops improving.
SHA-256 copying, independent destination verification and source-retention
checks remain in place. Cloud filesystem completion does not imply that a
provider has finished its subsequent remote upload.

The 1.4.0 themes, compact library, colour previews and file tools are retained.
New downloads use AstroArchive1.5.0.1.exe. Existing archives and settings are
preserved. Windows regression, build and installation/UI smoke checks gate the
release. Planning documents are not included.
