AstroArchive 2.1.4
Package 2.1.4.1

- Restoring or focusing the application no longer scans Edited folders on the
  interface thread. Automatic scans run in the background when Edited is visible,
  keeping navigation responsive and combining repeated restore/focus events.
- Unchanged Edited scans preserve selection, sorting and the current preview.
  Cancelled or stale scans cannot replace newer results or a different repository.
- The sky map returns to a single capture indicator for individual files, groups
  and stacks, using the recorded capture time. Observing paths are removed.
  Below-horizon blanking and sky-view navigation remain available.
- Includes the visible backup controls: Repository > Back up archive… and
  Settings > Backups, with folder/ZIP backups and restoration instructions.
