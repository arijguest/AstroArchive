AstroArchive 1.13.16
Package 1.13.16.1

- Export to… offers PixInsight, Siril, DeepSkyStacker, GIMP, Photoshop,
  AutoStakkert! 4, AstroWizard and Stacking Wizard in one compatible chooser.
  Repository image handoffs use verified Edited working copies. Subframes and
  recordings use verified export folders. DSS loads typed file lists, with
  separate lists and a group chooser for incompatible captures. Some stackers
  need the user to load the exported inputs in their own window.
- Export destinations settings store defaults per file type and an optional
  subframe-folder default. Application locations can be detected automatically
  or configured. Export asks for an unavailable app before creating copies.
  Existing Siril and StackingWizard preferences are retained.
- Export menus now offer Export to…, Save files…, Stacking folder… and More.
  Metadata/folder extras and advanced stacking options expand when needed.
  Edited uses the same Export to… chooser. Completion keeps its folder action.
- Original formats and precision are retained; conversions remain explicit.
  Launch failures retain verified files and offer their location and settings.
