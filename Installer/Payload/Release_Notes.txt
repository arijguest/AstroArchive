AstroArchive 1.4.0 — compact library, themes and image previews
Package 1.4.0.1

A compact six-column library and smaller header make more space for captures.
System, Light and Dark themes apply to the library, settings, dialogs and menus.
The preview pane can be resized or hidden; detailed capture metadata lives there.

Preview FITS/gzip FITS, colour and Bayer CFA images, and XISF with zlib/LZ4
compression. Windows image codecs provide TIFF, PNG, JPEG and other raster
formats; camera RAW compatibility depends on an installed codec.
Choose Linear, Auto, Strong or per-channel autostretch. Previews are sampled for
responsiveness and never modify source pixels. Archive imports remain FITS-only.

The file tools from 1.3.0 remain: selected deletion/export, ready-to-stack folders,
matching calibration availability, repository selection in Settings and verified
release downloads. Context menus also offer preview, path copy and selected CSV.

New downloads use AstroArchive1.4.0.1.exe. Existing repositories and settings
are preserved. Windows validation and checksums accompany the automated release.
