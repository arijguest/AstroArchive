AstroArchive 2.1.6
Package 2.1.6.1

- Fixed stacking exports losing valid calibration frames when selected subframe
  groups span sensor temperatures or observing nights. Each subset gets its
  matching dark/flat/bias set; folders separate automatically when sets differ.
  Compatible subs using the same set remain together.
- Calibration availability, exported folders, match review and DSS file lists
  now use the same grouping plan. Dark flats stay with their matching raw flats.
- Unknown processing-state confirmation is visible beside the main calibration
  options. The dialogue explains when calibration files are omitted until those
  subs are confirmed uncalibrated. Already calibrated inputs receive no extra
  calibration.
- Includes the larger Edited preview, formatted Help and walkthrough, and all
  previously published fixes.
