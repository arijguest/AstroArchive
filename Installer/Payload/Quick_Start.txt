AstroArchive 1.13.10
Windows 10/11 x64; .NET Framework 4.8.

START HERE
1. Choose Repository > Choose repository folder.
2. On Import, choose a source folder and a unique physical telescope ID.
3. Scan folder, review the results, then import the eligible files shown.
4. Browse Repository by target, search or Filters. Expand a session summary to
   see its subframes; stacks stay separate.
5. Select captures and use Export to copy files or prepare a stacking project.
The purple page selector switches Repository, Edited and Import. Ctrl+1–3 selects
a page; Ctrl+Tab cycles pages.
Originals are kept by default. Imports verify copies and skip duplicates.
Stacking and image processing take place in your external software.

GUIDE AND TOOLTIPS
F1 opens help for the current page. Guide > Search the guide searches titles
and full text; enter several words to narrow results. Ctrl+F focuses help search.
Hover over controls and headings for concise hints. Help is available offline.
Guide > Interactive walkthrough shows the main controls without importing files.

IMPORT WORKFLOW
1. Choose your repository, then open Import.
2. Select a saved telescope, or enter a unique ID and Browse its source folder.
   Import > Saved telescopes > Save telescope stores the device and association.
3. Leave model and camera on Auto unless an override is needed. Solving and
   rotation are Off by default. Import > Import options controls these choices.
4. Scan folder reviews supported files without copying them. Default filename
   matching skips known captures and completed dated DWARF sessions. Robust import
   matching checks changed same-name files, metadata and missing archive copies.
   Full rescan revisits known files and additions to previously imported sessions.
5. Review target, frame type, status and detected values. Use Filters and search
   to narrow the scan; import copies the eligible files in the current view.
6. Import new files copies and verifies them. Review and recovery shows failures.
Cancel retains completed imports. Resolve errors and scan again to resume.
Change the source, model, camera or filename exclusions before rescanning.

LIBRARY WORKFLOW
Choose a target on the left or All targets. Search filenames, catalogue IDs,
common names, dates or device details. Filters narrows the view; Clear resets it.
Repository starts with Session summaries: repeated Light subframes from the same
session, target and instrument share a collapsed row with dates, count, known
exposure and filters. Expand it to inspect files. Repository > View > Show all
files restores a flat table. Stacks and unmatched files remain separate.
Ctrl-click toggles files; Shift-click selects a range. Right-click for preview,
metadata, export or deletion. Bulk actions may use all captures in the filtered view, including collapsed
summaries, when no files are selected; review their count before accepting.
The path below the table opens the repository folder in File Explorer.

USB TRANSFER AND SAVED TELESCOPES
Connect the telescope as local USB storage so Windows exposes its USB volume.
On Import, select or save a telescope with a unique physical device ID and source
folder. Import > USB telescopes lists recognised connected devices; choose one
for a verified upload. Originals stay on the device and analysis stays off.
Use Import from telescope for a connected saved device. Reconnect and import
again for new captures. Enable Robust import matching to restore missing copies.
Fast matching retains skipped source originals; new copies are always verified.
Recover from repository adds saved device profiles; save a source association
before using a recovered profile for USB upload.
Rename saved telescope changes its archive labels and paths, preserving images
and session identities. Close other writers before renaming.

IMAGE PREVIEW AND TABLES
Select a file for Preview. Double-click an Edited image or use the file's
Preview image action for a larger window. Repository > View opens an external
image or hides the preview pane; drag the divider to resize it.
Scroll or pinch to zoom. Drag or use the arrow buttons to pan after zooming.
Fit or F restores the full image; plus/minus zoom; Escape closes the popup.
Preview keeps controls and capture sky visible while loading a new image.
The text-free sky globe uses capture time and location when available, or
celestial coordinates otherwise; hover for the recorded context.
Landscape images display rotated into portrait. Large still previews are sampled,
so use your editor for inspection at the original pixel resolution.
Stretch changes the display only. Scientific images default to Auto per channel;
saved choices are retained. Solar, lunar, planetary and processed raster images
start with Linear. Source pixels and headers remain unchanged.
Click headings to sort; click again to reverse. Shift-click adds a sort column.
Right-click a heading to choose columns. Drag headings to reorder them; layouts
save independently for Repository, Import and Edited. Restore default columns
resets the layout. A dash indicates missing metadata, not zero.

EDITED IMAGES AND WORKING COPIES
Edited has targets, a table and Preview. All projects shows every project;
choose a project to narrow the list. Search or filter by object, class or name.
Add images copies files into a new or existing project. Import folder offers
Browse and Scan, including an optional subfolder crawl and review before copying.
Repository/database folders and originals already archived are skipped, including
renamed byte-identical copies. Sources stay in place. Unreadable files are excluded.
Sending a repository stack to Siril creates a verified Edited working copy.
For AstroWizard or another editor, Export > Create Edited working copies opens a
project folder for manual loading. Save outputs there; Refresh finds them. Edited duplicate review identifies byte-
identical copies across projects and retains acquisition originals.
Use Open project folder, Enlarge, Image details or Open in editor on Edited.
Projects move with the repository and remain separate from acquisition captures.

EDITED METADATA AND EXPOSURE
Starless and Stars only labels are recognised in filenames. Object, filters,
coordinates, sub counts and exposures come from image metadata or explicit names.
For example, M31_Ha_120x60s_starless means 120 subs of 60 seconds, 7200 seconds
in total, and Ha. Mixed durations retain their total without a guessed per-sub value.
30s40 means a 30-second sub and gain 40; DWARF's stacked-16 is image bit depth.
An unspecified EXPTIME/EXPOSURE value is kept as reported exposure, without
assuming it is per-sub or total. Unknown values remain unknown. Image details
shows the evidence and conflicts. Compatible single-source editor outputs can
inherit missing acquisition data from their working copy.
Hover over Exposure in Repository or Import to inspect reported header values.
Subframe summary totals count acquisition subs only and exclude stack exposures.

GIF AND VIDEO PREVIEWS
GIF, SER, AVI, MP4, MOV, M4V, WMV and MKV can be imported and viewed.
Moving images have Pause / Play in the toolbar below Preview. Playback pauses
when leaving the page. SER uses a 10 fps preview rate, not an inferred capture rate.
Other videos require compatible Windows codecs; Preview reports unavailable playback.
A GIF matches a still image in the same folder when their filename stems match,
or it adds _processing, _progress, _animation, _animated, _process, _timelapse,
_before-after or _edit-history. Only a unique match inherits missing object,
exposure, sub-count and filter data. Ambiguous matches and conflicting metadata
are not guessed. Originals are retained.

CATALOGUE IDENTITIES
Search catalogue IDs or common names. Aliases share a target: M106, NGC4258,
UGC7353 and PGC39600 resolve to M106. Catalogue prefixes matter: M106 and NGC106
are different objects. Bare numbers and ambiguous aliases do not establish an ID.
Caldwell IDs and leading-zero variants are recognised. Moon/Lunar appears as Moon;
Sun/Solar appears as Sun. Meteor filenames use Meteor and leave object ID blank.
The word meteor must be in the filename; meteorite and folder names do not match.

STACKING PROJECTS AND SESSIONS
Select captures and choose Export selected files for original copies, or a
stacking export with Subs, Stacks or Both. Choose an existing destination.
Stacks export as image files; subs retain compatible input folders.
Add Metadata and Create new folder are both off by default. Add Metadata includes
a checksum manifest, saved session metadata and readme/workflow notes. Metadata
already inside an image is preserved. Create new folder adds an enclosing folder.
Existing files are kept; duplicate filenames receive a numbered suffix.
For stacking exports, Separate sessions is off by default and can keep each
acquisition session apart.
Inputs are separated by target, physical device, camera, filter, dimensions,
binning, Bayer pattern, exposure, gain and calibration state.
Do not combine stacks with their constituent subs or overlapping live-stack snapshots.
Copies are verified and originals remain unchanged.
Stacking runs in the external program of your choice.

CALIBRATION AND FITS CONVERSION
Calibration matching shows Accepted, Needs review or Rejected candidates.
Review missing/conflicting identity, camera, gain, geometry or processing details.
Flats also need compatible filter, night and optics. Darks match exposure and known
temperatures within 3 degrees C. Processed lights receive no extra calibration.
Unknown calibration status requires explicit inclusion.
Dark flats match raw-flat exposure in separate sets;
do not subtract both a bias and a dark flat from the same flat.
Convert supported images to FITS is an explicit export option for eligible linear
images. Confirm linearity in Edit metadata. Selected pages/slices are converted
without a display stretch, and originals are retained. Cancelled or failed exports
keep completed, verified copies and remove unfinished temporary copies.
Wait for Export complete before using a full set of stacking inputs.

METADATA AND OPTIONAL ANALYSIS
Right-click Edit metadata to correct indexed labels without rewriting image headers.
Re-detect metadata and review shows detected values before applying selected fields;
recorded user changes retain priority. Choose HDU / page / frame selects a container
image for supported pixel operations. Movie preview plays the recording.
Target identification needs ASTAP plus its star database, or an Astrometry.net
account/API key and an internet connection. Configure them in Settings > Plate solving.
Online solving sends detected star coordinates. Review ambiguous target suggestions.
Rotation analysis needs timestamped acquisition subs, adequate time coverage and
observing location/pointing data. Stacks and registered images are unsuitable.
Mount labels ending in ? are suggestions. Confirm them through Edit metadata.

OBSERVING TOWN / CITY
Settings > Import and processing > Copy workers and observing site opens the
observing-site controls. Search the offline town/city picker by name or region,
or enter coordinates. Place-centre coordinates approximate your observing site;
use precise coordinates when needed for rotation analysis.
Location searches do not send your position to a network service.

DUMP INBOX
Each repository has a Dump folder. Drop FITS files or telescope folders there
and finish copying before processing. Startup and repository switching process
Dump automatically when FITS files are pending; Import > Dump folder can open it or process it manually.
A progress window shows status and Cancel. Verified imports and duplicates are
removed; changed, locked or failed inputs stay for retry. Other files stay in place.
Mixed drops use an Unknown physical device ID; correct it through Edit metadata.

REVIEW, EXCLUSIONS AND DELETION
Import > Review and recovery separates rejection, integrity and transfer issues.
Flagged captures are skipped by default; inspect them before allowing import.
Retry failed imports retries the failed transfers in the filtered scan. Changed
sources need a fresh scan. Completed imports remain available after cancellation.
Ignore non-raw files (PNG/JPG/JPEG) defaults on; its setting is saved.
Import options > Ignore failed skips filenames containing failed, regardless of
case, in folder, USB and Dump imports. Rescan after changing this option.
Repository's Delete failed tool lists matching indexed filenames for confirmation.
Delete selected files removes archive copies, retaining source files and shared metadata.
Deletion history prevents reimport of deleted checksums. Its reimport permission
allows a later import from an available source; it does not restore deleted files.
Remove source originals is optional. Only verified, safely removable imported
originals are removed; duplicates, failed cleanup and other source files are retained.
Delete all archive data permanently clears indexed captures and managed metadata.
Edited projects, deletion history, source mirrors and unindexed files remain.
Review the confirmation and back up wanted images first.

CLOUD FOLDERS AND BACKUPS
Choose a filesystem folder exposed by Windows, including mounted cloud storage.
Browser-only folders cannot be used. Alt+D in the folder picker lets you paste a path.
Make cloud inputs available offline to avoid on-demand download waits. Directory
links are skipped. Cloud sync may continue after AstroArchive finishes copying.
Move or back up the whole repository, including .astroarchive/index.sqlite and
Edited projects. Use one writer per repository. Application uninstall retains data.

INSTALLATION AND UPDATES
Run the installer for a fresh installation, update or repair. The default location
is %LOCALAPPDATA%\Programs\AstroArchive and requires no administrator access.
The desktop and Start menu launcher checks for releases. Later opens the installed
version. Settings > Check for and install releases checks from inside the app.
Install release downloads and verifies the installer, saves state, and restarts
the app after setup. Updates retain repositories, settings and local codecs.
Manual installation works offline. Start.exe --no-updates skips startup checking.
Uninstall through Windows Installed Apps; repositories and settings are retained.

SUPPORTED FILES
FITS/gzip FITS: supported image HDUs, RGB/Bayer data and selected cube slices.
TIFF/PNG/XISF: supported numeric layouts; eligible linear images can be converted.
JPEG/GIF: display and original-file export, with animation for GIF.
SER: planetary playback and frame selection; export the recording for processing.
AVI/MP4/MOV/M4V/WMV/MKV: Windows codec playback and original-file export.
CR2/CR3/NEF/ARW/DNG: original-file import/export; external RAW previews need a
compatible Windows image codec. Other Windows image formats may preview externally.
Tile-compressed FITS (.fz) needs optional CFITSIO for pixel decoding; Zstandard
XISF needs its optional codec. Missing codecs leave original-file export available.
Settings > Image compatibility shows support and opens the optional codec folder.
Compatible x64 cfitsio.dll/libzstd.dll and dependencies go in
%LOCALAPPDATA%\AstroArchive\codecs; restart the app after installing them.
Scientific decoders/conversions have size and pixel-layout limits. Complex XISF
encodings and unsupported processed data remain original-file exports.

APPEARANCE AND ACCESSIBILITY
Settings > Preferences changes appearance. Settings > Accessibility controls text
size, comfortable rows, high contrast and reduced progress animation.
Alt reveals menu access keys; arrows navigate menus and Tab moves between controls.
Processing shows temporary progress and Cancel; Dump uses its own progress window.
Repository > Diagnostics opens performance details and the last import report.

KEYBOARD SHORTCUTS
Main window: Ctrl+F searches; Ctrl+I opens Import; Ctrl+E opens Export; F1 opens page help.
Tables: Ctrl-click toggles selection; Shift-click selects a range; Shift-click a
heading adds sorting. Delete on Repository opens a deletion confirmation.
Preview: F recenters; plus/minus zoom; arrows pan; Escape closes the popup.
Guide: Ctrl+F searches, Up/Down selects topics, Ctrl+C copies text, Escape closes.
Folder picker: Alt+D focuses its address bar.

TROUBLESHOOTING
Import disabled: choose a repository, existing source folder and device ID, then
scan. Wait for active work to finish. Check that the filtered scan has eligible files.
No rows: Clear search/filters, choose All targets or All projects, and check the
repository. Expand session summaries to see individual acquisition files.
USB missing: check its Windows USB volume, Browse its capture folder and save the
association. Refresh connected devices. USB upload uses local storage, not Wi-Fi.
Import failure: read the scan/import report, check the file path and free space,
and make cloud inputs available offline. Resolve the problem and scan again.
Missing archive file: verify checksums, enable Robust import matching, then import
from the original source to restore it.
Slow import: leave solving/rotation off and inspect Diagnostics. More workers
cannot guarantee faster storage or cloud downloads.
Preview unavailable: check the reported format/codec or size limit. Use a compatible
Windows codec for RAW/video, or open the original in your processing software.
Unknown exposure: inspect Image details or the Exposure tooltip. A filename gain
or unspecified EXPTIME does not establish total integration.
Solving/calibration uncertain: check solver settings, observing data and relevant
camera/exposure/processing metadata before applying an inference.
Windows blocked a file: check the release's signing status and Windows Security.
Application Control policies may require approval of the publisher. Setup errors:
%TEMP%\AstroArchive-setup-error.txt. Update errors:
%LOCALAPPDATA%\AstroArchive\updates\last-error.txt.
Include app/package version, the exact error and relevant filename when reporting
an issue at https://github.com/arijguest/AstroArchive/issues.

FRAME TYPES AND GLOSSARY
Light / sub: one acquisition exposure.
Stack: a combined or registered result, kept separate from its source subs.
Dark: covered sensor exposure. Flat: uniform-field exposure for illumination/dust correction.
Bias / offset: short or zero-duration exposure for sensor readout offset.
Master calibration: combined dark, flat or bias, distinct from raw calibrations.
Starless / Stars only: edited image layers recognised from filename labels.
Session: related acquisition group. Device ID: one physical telescope, not its model.
Plate solving: finding an image's sky position. Repository: archived originals and metadata.
Edited project: mutable working copies and outputs kept with the repository.
