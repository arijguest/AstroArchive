AstroArchive 1.5.0 validation

The Windows release workflow runs generated application regressions, installer
and update regressions, .NET Framework 4.8 x64 builds, application/installer UI
rendering, and disposable install/repair/uninstall smoke checks. Only a successful
workflow can publish the installer and SHA-256 update feed. The matching workflow
logs are the authoritative results for this package.

New regressions exercise first-file copy/verification ETA, unknown scan totals,
stalls, retries, failed files, finalisation, old-phase callbacks, bounded progress
notifications, snapshot isolation, compact filename phrases, trusted header cache
invalidation, discovery spill/cancellation, concurrent session JSON loading, and
export progress. Windows-only tests validate real file identity and source cleanup.

Linux/Mono synthetic profiling is supplementary: it does not establish WPF,
Windows-native behavior or authenticated cloud-provider performance. Real capture
collections and live provider delays require measurements on the user's storage.
The solver protocol regression uses a test double, not a real astronomical solve.
