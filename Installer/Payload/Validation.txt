AstroArchive 1.10.3 validation
Package 1.10.3.1; Windows 10/11 x64; .NET Framework 4.8.

The Windows release workflow runs application regressions, a separate five-case
Windows WIC integration suite, installer/updater regressions, x64 compilation,
WPF application/installer rendering and disposable install/repair/uninstall checks.
A successful workflow is required before publishing installers and the SHA-256
update feed. Its logs are authoritative for test counts and package hashes.

Windows navigation checks exercise ordered menus in both themes, source and file
action availability, repository path/branding placement, rendered ascending and
descending sort indicators and multi-column priorities, accessible header names,
larger text and comfortable rows, high contrast, reduced progress animation,
walkthrough navigation, author attribution and the idle status bar. The preview regression additionally checks rendered quadrant pixels in 16
portrait/landscape/square/upscale, resize and bitmap-DPI cases, and exercises
zoom/pan/Fit button availability and actions. Rendered
previews are retained in the workflow artifact for visual review.

Supplementary validation in Linux compiles the application, installer, launcher,
engine and raster test executables against official .NET Framework 4.8 references.
Engine regressions run under Mono/system SQLite; platform/optional-codec cases
are reported separately. CFITSIO tile compression and Zstandard fixtures pass
with independent system codecs. WIC tests compile here but execute only in the
Windows workflow; Linux does not establish WPF or Windows-native behavior.

Compatibility fixtures cover FITS HDUs/cubes/gzip/scaling, numeric XISF attachment
and base64 layouts, zlib/LZ4/shuffle/Zstandard, CFA metadata, SER byte order/frame
selection, explicit vendor/software recognition, normalized metadata units,
gain/electrons-per-ADU separation, timezone uncertainty, retained user and legacy
edits, reviewed re-detection, calibration conflicts, mixed-exposure dark-flat
recipes, verified sidecars and derived FITS source/output identities. Existing
mosaic, USB upload, import review/recovery, progress and processor-handoff tests
remain in the suite. Windows WIC cases exercise 16-bit TIFF/PNG preservation,
multi-page selection, RGB order/derived FITS and JPEG scientific-export exclusion.

Optional CFITSIO/Zstandard DLLs are not shipped; Windows provisioning of specific
third-party builds needs independent validation. Live telescope collections,
undocumented vendor mirrors, provider/storage delays and actual ASTAP catalogues
or authenticated online solves were unavailable. The ASTAP protocol test uses a
test double. AVI/camera RAW archive support does not claim a bundled pixel decoder.
SER recordings are planetary inputs, not automatic deep-sky stacking inputs.
Stacking, calibration/master generation and stitching use external software.
