# Original offline installer

The user-supplied AstroArchive 1.2.0 Windows x64 offline installer is preserved
byte-for-byte here. Application version: 1.2.0; installer package: 1.2.0.1.
Its SHA-256 is recorded alongside the executable.

This original package has manual updates. Install the latest release once to
receive the launcher that checks GitHub for future updates at startup.
Repositories, images and settings are retained by an in-place upgrade.

See [the project README](../../README.md) for current installation instructions.
