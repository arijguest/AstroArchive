AstroArchive 1.13.4 validation
Package 1.13.4.2; Windows 10/11 x64; .NET Framework 4.8.

The Windows release workflow runs application regressions, a separate six-case
Windows WIC integration suite, installer/updater regressions, x64 compilation,
WPF application/installer rendering and disposable install/repair/uninstall checks.
A successful workflow is required before publishing installers and the SHA-256
update feed. Its logs are authoritative for test counts and package hashes.

Incremental-scan checks cover durable completed manifests, physical volume and
stable telescope identity, obsolete classification/model changes, cloud exclusion,
and reliable change-time. A Windows fixture imports 100 old files, adds one file
to that folder and one to a new subfolder, then verifies only two headers are
read while all 102 entries remain in progress accounting. Full rescan reads all
102 headers and hashes sources without cache hits. Additional checks cover
new/changed/deleted sidecars, nearer session metadata, missing archive copies,
source rewrites with restored timestamps, skipped-original retention and repeated
USB upload accounting. Real-device speed depends on media and collection size;
FAT/exFAT inventory does not prove unchanged content when size/time are preserved.

Progressive preview checks exercise Repository/Edited loading in light/dark and
100/150% text: stable blank-image geometry/sky bounds, immediate capture-time sky,
disabled empty-image controls, Linear-before-stretch pixels, cancelled display
passes, slow codec/rapid latest selection, skipped intermediate frames, cache
revisits and decode failure isolation. Engine checks cover linear ranges/colour,
invalid pixels/origin/cancellation, cache metadata isolation, file length/time
invalidation, separate HDUs/sequence frames, eviction and the 64 MiB limit.

Page navigation checks verify grouped left action buttons, the centred accent
dropdown in both inline and separate rows without clipping/overlaps, page/content
and selection/filter/import-state retention, synchronization with menu navigation,
forward/backward keyboard cycling, removal of the old tab strip, six-pixel gaps,
light/dark popup contrast, high contrast, and narrow/normal window layouts at
100/150% text sizes at 1060/1380/2400 widths. The interactive guide highlights
and opens the selector.
Shared search regressions cover phrases, exclusions, OR, scoped fields, numeric
comparisons, catalogue aliases, wildcards and malformed queries. Import checks
cover default/migrated exclusions, saved opt-outs, pre-metadata filtering,
import rechecks, USB/Dump policy and Unknown-only target assignment. Purge checks
retain Edited and scientific originals. Legacy Mosaic metadata does not prevent
ordinary stacking exports; WCS remains available for sky/plate-solve workflows.
Native UI checks exercise import parameter tabs, search guidance and Unknown
target assignment, plus theme/scale layouts. Progress is an owned window and
follows minimising, restoring and hiding the application.
Native window-icon checks verify the bundled ICO retains 16/32-pixel frames,
uses the shared frozen image and supplies Windows with both small and large icon
handles for the main window, forms, guide and preview. Shell checks verify stable process/window/shortcut AppUserModelIDs,
a hash-matched logo cache and repaired pins targeting removed version folders.

Capture sky regressions check sidereal time, longitude signs, northern/southern
and polar horizons, acquisition clocks and offsets, missing/ambiguous clocks,
capture-site precedence, pointing/catalogue provenance, non-UTC header standards,
full constellation coverage and vector normalization. Native WPF checks verify
both preview surfaces in light/dark and 100/150% text: maximum image fit, remaining
space and height-limited hiding, aspect changes, all four image quadrant pixels,
text-free cached drawings, interactive orbit/zoom without editing captures,
routed scroll/keyboard inputs, touch support, view retention/reset and its overlay,
accessible header icons and details popup/Escape. IC common-name checks cover
existing labels, filters, search, aliases and nested-name filename ambiguities.
Session checks cover group selection, individual files, Ctrl/Shift, deduplication,
right-click membership, expansion/refresh retention, filtered-out groups, matching
row typography, roomy chevrons and default Frame Type sorting. Edited regressions
check fuzzy catalogue/common names, custom archive targets, header/ID precedence,
ambiguous matches, acquisition inheritance and add/import/refresh integration.
Native WPF checks cover GIF class filtering and the visible sortable File Type
column with Total Exposure hidden by default. Layout regression checks cover the
one-time older Edited layout upgrade, custom headings and later saved user choices.
Progress tests minimise/restore active operations and Dump windows,
start/update/finish them while minimised, and retain safe cancellation behavior.
The combined release retains session summaries, Edited
browsing, GIF/SER/video playback and the existing Windows installation tests.

Windows navigation checks exercise ordered menus in both themes, source and file
action availability, repository path/branding placement, rendered ascending and
descending sort indicators and multi-column priorities, accessible header names,
larger text and comfortable rows, high contrast, reduced progress animation,
walkthrough navigation, author attribution and the idle status bar. The preview regression additionally checks rendered quadrant pixels in 16
portrait/landscape/square/upscale, resize and bitmap-DPI cases, and exercises
zoom/pan/Fit button availability and actions. Rendered
previews are retained in the workflow artifact for visual review.

Supplementary validation in Linux compiles the application, installer, launcher,
engine and raster test executables against official .NET Framework 4.8 references.
Engine regressions run under Mono/system SQLite; platform/optional-codec cases
are reported separately. CFITSIO tile compression and Zstandard fixtures pass
with independent system codecs. WIC tests compile here but execute only in the
Windows workflow; Linux does not establish WPF or Windows-native behavior.

Compatibility fixtures cover FITS HDUs/cubes/gzip/scaling, numeric XISF attachment
and base64 layouts, zlib/LZ4/shuffle/Zstandard, CFA metadata, SER byte order/frame
selection, explicit vendor/software recognition, normalized metadata units,
gain/electrons-per-ADU separation, timezone uncertainty, retained user and legacy
edits, reviewed re-detection, calibration conflicts, mixed-exposure dark-flat
recipes, verified sidecars and derived FITS source/output identities. Existing
USB upload, import review/recovery, progress and processor-handoff tests
remain in the suite. Windows WIC cases exercise 16-bit TIFF/PNG preservation,
multi-page selection, RGB order/derived FITS and JPEG scientific-export exclusion.

Optional CFITSIO/Zstandard DLLs are not shipped; Windows provisioning of specific
third-party builds needs independent validation. Live telescope collections,
undocumented vendor mirrors, provider/storage delays and actual ASTAP catalogues
or authenticated online solves were unavailable. The ASTAP protocol test uses a
test double. AVI/camera RAW archive support does not claim a bundled pixel decoder.
SER recordings are planetary inputs, not automatic deep-sky stacking inputs.
Stacking, calibration/master generation and stitching use external software.

Menu input checks compare small touchpad deltas with full wheel notches, accumulate
rapid packets before layout, reverse direction immediately and check menu limits
and nested scroll ownership. Popup checks retain both themes and 100/150/200%
layout scales. Preview checks exercise reversed button/keyboard directions and
verify the toolbar fits directly below the image in both preview surfaces.
Sixteen pixel-rendered image/DPI/resize cases continue to verify full-image fit.

Update-policy diagnostics preserve the native error and saved installer, handle
event-access failures and match rejected device paths instead of parent processes.

Source-history regressions use DWARF_RAW_TELE_C 20_EXP_30_GAIN_40 plus its full
millisecond session timestamp, and parent paths with underscores and percent.
They cover imports made from both parent/session roots, history deduplication,
other-device folder-name collisions and checksum duplicate lookup outside the
source-scoped snapshot. Windows checks verify no payload reads or old-row callbacks
across browse-root changes, discover added exposures, exercise FAT-style saved
inventory stamps and retain Full rescan bypass. Existing sidecar/change-time,
restoration, USB, original-cleanup and progressive-preview checks remain in place.
Windows USB regression also starts with a capture imported from a PC mirror,
recognizes the card copy by checksum, remembers its current sidecars and skips
later payload reads. It retains user metadata, checks changed sidecars and handles
a verified identical rewrite of the archived copy without trusting its old stamp.
