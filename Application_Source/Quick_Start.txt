AstroArchive user guide
Windows 10/11 x64; .NET Framework 4.8.

START HERE

1. Open Settings > General > Choose repository.
2. On Import, choose a capture folder and a unique physical telescope ID.
3. Scan folder, review the metadata, then import the eligible files shown.
4. Browse Repository by target, search or Filters; expand sessions to see subs.
5. Select files and use Export for copies, stacking inputs or external processing.

Imports verify copies and skip duplicates. Source originals are kept by default.
Stacking and image processing run in your external software.

GUIDE AND TOOLTIPS

F1 opens page help. Guide > Help searches titles and full text; Ctrl+F focuses
search. Guide > Interactive walkthrough introduces controls without importing.
Less obvious menu options have concise hover hints.
Checkboxes show an empty outline when off, a tick when on and a dash when mixed.
Unavailable controls keep their recorded state and readable labels.
Delete originals shows On/Off and explains when a scan is needed.

IMPORT WORKFLOW

## Scan and import
Choose a saved telescope or Browse a folder. Leave model/camera on Auto unless
an override is needed. Target and rotation analysis default Off.
Scan folder reviews files; Import copies eligible captures in the filtered view.

## Repeat imports
Default filename matching skips known captures and completed dated DWARF sessions.
Robust file matching revisits same-name edits, sidecars and missing archive copies.
Import > Review and repair > Full rescan reads and hashes every source file.
Cancel keeps completed imports. Changed sources need a new scan.

LIBRARY WORKFLOW

## Find and select files
Choose a target or All Targets. Search IDs, common names, dates, filenames or
device details. Combine terms: M45 Dwarflab, M45 S50 Pro, M45 stack.
Quotes or file: search literal filename text. Clear resets search and filters.
Selections survive target changes. The top-right counter shows the batch total;
click it or press Escape to clear. Ctrl-click toggles; Shift-click selects a range.

## Condensed subs
Repeated Lights share a collapsed session row with dates, count, per-sub exposure,
total integration and filters. Mixed durations show a range; missing values remain
unknown. Expand the row or turn off Repository > Group subs by session.
Stacks remain separate. Known counts show Stack (1445); filters still use Stack.

USB TRANSFER AND SAVED TELESCOPES

## Connect and import
Expose the telescope as a Windows USB volume. When recognised, Import offers
**Import from Seestar…** or **Import from Dwarflab…**; the connected-import button
opens the same picker. Choose a saved physical telescope or name a new one.
Use **Add folder…** and **Add files…** to select captures on that telescope drive.
Folders include subfolders; overlapping selections are scanned once. Previous
selections are remembered for that telescope and volume.
For faster scans, choose only the target folders or files you need. **Entire
telescope drive** checks all capture folders and may take a long time.
**Review and import…** asks for confirmation before any scan or copying. Whole-drive
and 500-or-more-file selections receive a stronger time warning. Cancel or No
leaves the selection unimported.
After confirmation, every selected capture is fully scanned and hashed, then
eligible files are screened and copied with verification. Saved filename/session
shortcuts are bypassed even when Robust file matching is off. Import exclusions
still apply; rejected or unreadable captures remain for review.
Connected imports keep originals and leave analysis off. Cancel retains completed
copies; reconnect and select the captures again to resume or repair missing copies.

## Manage profiles
Import > Saved telescopes saves, renames or recovers profiles from archive data.
Recovered profiles need a source association before USB import.
A physical telescope ID identifies one device; its model can be shared.

ARCHIVE SAFETY AND BACKUPS

## Create and restore a backup
Repository > Back up archive… copies images, Edited and the current database to
a verified folder or lossless ZIP outside the archive. Prefer a separate drive.
Close other writers/editors. Cancel removes the incomplete backup, keeping earlier
backups. Restore by selecting the backup's Repository folder; Restore.txt and
backup.json contain instructions and checksums.

## Protect originals
Settings > Backups > Protect originals can prevent accidental deletion/renaming
on local NTFS drives. Edited, Dump and metadata remain writable.
Turn protection off before moving the archive in Explorer.
The Windows owner can change permissions; protection is not a backup.

IMAGE PREVIEW AND TABLES

## Preview
Select a file for the sidebar; open Preview image for a larger window.
Repository's wider preview pane is adjustable by dragging its divider.
Sidebars sample still images, normally to 1,400 pixels on the longest edge.
Large still/SER windows decode native pixels within format limits.
Preview never resizes or rewrites source files.

## Zoom and display
Scroll or pinch to zoom; drag or use arrows to pan. Fit or F recenters.
Plus/minus zoom; Escape closes the popup. Large previews open in source orientation;
Rotate left/right changes the display. Stretch changes display values only.
Scientific images default to Auto per channel; processed/planetary images use Linear.

## Tables and target groups
Click a heading to sort; click again to reverse. Shift-click adds a sort column.
Right-click to choose columns; drag to reorder. Each page saves its layout.
Targets show the preferred ID first: M31 - Andromeda Galaxy.
All Targets is bold and shaded; comets share Solar system. Meteors sit above
Other targets. All Targets orders merged subs, stacks, ungrouped files, calibrations.
Individual targets: stacks above lights. Sorts apply within each section.

EDITED IMAGES AND WORKING COPIES

## Add and browse
Edited keeps working copies and returned outputs with the repository.
Add images copies files. Import folder scans with optional subfolders and a review.
Archived originals and byte-identical Edited files are skipped; changed files
can become new versions. Unchecked entries leave existing files untouched.
RAW/scientific types are grouped first by type; GIFs are last.

## Export and delete
Export to… opens supported working images in your editor. Save outputs alongside
the working copy; Refresh finds them. Settings > Export stores app defaults.
Right-click Export files… copies individual or multiple selected images, verifies
their bytes and adds suffixes for filename collisions.
Delete files… or Delete confirms removal of Edited copies. Source originals and
archived captures remain. Right-click also offers preview, details and file location.

EDITED METADATA AND EXPOSURE

Select images > Edit metadata to assign targets, filters, class, exposures, sub
counts or coordinates. Empty/unchanged fields retain values; files are not rewritten.
Starless and Stars only labels are recognised in filenames.
120x60s means 120 subs of 60 seconds; 30s40 means sub exposure/gain.
DWARF's stacked-16 is bit depth. Unspecified EXPTIME stays reported exposure;
it is not assumed to be per-sub or total. Unknown/conflicting values need review.
Image details and the Exposure tooltip show evidence. Sub-summary integration
counts acquisition subs only, excluding stacks.

GIF AND VIDEO PREVIEWS

GIF, SER and supported Windows videos offer Pause/Play below Preview.
Playback pauses when leaving the page. SER previews run at 10 fps, not an
inferred capture rate. Other videos require compatible Windows codecs.

GIFs inherit missing acquisition data only from a unique nearby still with the
same stem or a processing/progress/animation/timelapse/edit-history suffix.
Ambiguous matches and conflicting metadata are not guessed.

CATALOGUE IDENTITIES

Aliases share an identity: M106, NGC4258, UGC7353 and PGC39600 resolve to M106.
Catalogue prefixes matter; M106 differs from NGC106. Spacing, accents and full
Messier/Caldwell prefixes are normalised. Conflicting IDs stay unresolved.
Rosette/NGC2244 labels use NGC2237. Moon/Lunar and Sun/Solar share labels.
Comet designations and recognised names such as NEAT/LINEAR/NEOWISE group in
Solar system. Meteor filename labels use Meteor and leave object ID blank.

Right-click a target > Edit name and aliases saves custom names in app settings.
Names cannot claim another object's identity. Use built-in names resets that object.

STACKING PROJECTS AND SESSIONS

## Choose an export
Export files… copies originals; Stacking folder… offers Subs, Stacks or Both.
Export to… verifies copies before opening supported inputs in external software.
DSS loads file lists. Siril opens the exported folder; other stackers may require
choosing the inputs. No app starts stacking automatically.
Choose subframes separately from finished stacks.

## Optional settings
Matching calibrations are optional; unknown calibration state needs explicit
inclusion. More options includes separate sessions and rejected-file choices.
Add Metadata and Create new folder default Off. Metadata adds manifests, session
details and workflow notes. Existing files stay; collisions get numbered suffixes.
Inputs are grouped by target, device, camera, filter, geometry and acquisition
settings. Different calibration sets stay separate.

## Single-stack handoff
Open with… after export can open one eligible FITS stack in Siril after verification.
Configure its location and export folder under Settings > Export.
Cancelled/failed exports do not launch it; launch failures keep completed copies.

Catalogue CSV exports metadata. Formula-like text is prefixed with a tab to avoid
spreadsheet execution; numeric columns retain their values.

CALIBRATION AND FITS CONVERSION

Matching labels candidates Accepted, Needs review or Rejected.
Camera/device identity, gain, geometry, binning, Bayer and processing state must
be compatible. Darks need matching exposure and known temperatures within 3°C.
Flats need compatible filter/night/optics. Processed subs get no extra calibration.
Dark flats match raw-flat exposure; do not subtract both bias and dark flat.

Convert supported images to FITS is explicit and requires confirmed linear data.
Selected pages/slices convert physical values without display stretch.
Originals remain. Cancel keeps verified outputs and removes unfinished copies;
wait for completion before processing the full set.

METADATA AND OPTIONAL ANALYSIS

## Metadata
Right-click Edit metadata changes indexed labels, retaining source headers.
More actions > Re-detect metadata and review compares detected values before
applying fields; user edits have priority. Choose HDU / page / frame selects a
container image for supported pixel operations.

## Target identification
Settings > Sky & solving > Plate solver setup configures ASTAP plus its database
or Astrometry.net with an API key. Online solving sends detected star coordinates.
Identify targets solves one representative per selected Light session/group;
stacks solve individually. Review batch matches before applying.
Cancel retains completed changes. Recognised names can identify files without a solver.

## Rotation analysis
Requires timestamped acquisition subs with enough time coverage and site/pointing
data. Stacks and registered images are unsuitable. Mount labels ending in ? are
suggestions; confirm them through Edit metadata.

OBSERVING TOWN / CITY

Settings > Sky & solving offers an offline town/city search or manual coordinates.
Place centres approximate your site; use precise coordinates for rotation analysis.
Location search does not send your position to a network service.

DUMP INBOX

Drop FITS files or telescope folders into the repository's Dump folder.
Finish copying first. Startup/repository switching process pending FITS automatically;
Import > Dump folder also opens or processes it manually.
Verified imports and duplicates are removed; changed, locked or failed inputs
remain for retry. Other files stay. Correct Unknown device IDs through Edit metadata.

REVIEW, EXCLUSIONS AND DELETION

## Review and retry
Import > Review and repair separates rejection, integrity and transfer issues.
Flagged captures are skipped by default. Retry failed imports uses the filtered scan;
changed sources need a fresh scan. Completed imports survive cancellation.

## Exclusions and deletion
Settings > Import can ignore failed filenames and PNG/JPG/JPEG inputs; rescan after
changes. Repository > Maintenance offers Delete failed and Purge non-raw files.
Delete files confirms archive-copy removal; source files and shared metadata stay.
Deletion history blocks reimport of deleted checksums. Allow reimport permits a
later source import; it does not restore deleted files.

Delete originals is optional and only removes safely removable, verified new or
restored source captures. Duplicates and failed cleanup retain originals.
Delete archive data clears indexed captures/managed metadata, keeping Edited,
source mirrors, unindexed files and deletion history.

CLOUD FOLDERS AND BACKUPS

Use folders exposed in Windows; browser-only storage is unsupported.
Make cloud inputs available offline and keep the whole repository, including
.astroarchive and Edited, together. Links are skipped. Use one archive writer.
Cloud sync can continue after copying; deletions in synced folders propagate.
Uninstall retains repositories and settings.

INSTALLATION AND UPDATES

Run the installer to install, update or repair. The default location is
%LOCALAPPDATA%\Programs\AstroArchive and needs no administrator access.
Settings > Updates checks releases, shows notes and offers Install and restart.
Automatic checks run after startup and every six hours while open; Activity and
Guide > About AstroArchive show availability. Disable checks in Settings > Updates.
Downloads show progress/Cancel in Activity. Failed downloads retain the current app.
Manual installation works offline; Start.exe --no-updates skips automatic checks.
Uninstall through Windows Installed Apps; user data and codecs remain.

SUPPORTED FILES

- **FITS/gzip FITS:** supported HDUs, RGB/Bayer and selected cube slices.
- **TIFF/PNG/XISF:** supported numeric layouts; eligible linear FITS conversion.
- **JPEG/GIF:** display, GIF animation and original-file export.
- **SER:** planetary playback, frame selection and recording export.
- **AVI/MP4/MOV/M4V/WMV/MKV:** Windows-codec playback and original-file export.
- **CR2/CR3/NEF/ARW/DNG:** original import/export; preview needs a Windows codec.

Tile-compressed FITS needs optional CFITSIO; Zstandard XISF needs its codec.
Settings > General > Image compatibility shows availability and the codec folder.
Scientific decoding has size/layout limits; ordinary exports preserve bytes.

APPEARANCE AND ACCESSIBILITY

Settings opens Preferences: General, Import, Export, Sky & solving, Accessibility,
Updates and Backups. Save preferences applies changes; Cancel retains settings.
Accessibility adjusts text size, rows, contrast and progress animation.
Alt reveals menu access keys; arrows navigate menus; Tab moves between controls.
The purple selector switches Repository/Edited/Import; Ctrl+1–3 selects a page.

The Activity bell beside Buy Me a Coffee (Ctrl+Shift+N) shows progress, ETA, Cancel,
reports and review actions. Closing it leaves work running; cancellation waits for
a safe stopping point. ETA covers the current stage. Conflicting changes wait.
Repository > Diagnostics shows timings and the latest import report.

KEYBOARD SHORTCUTS

- **Main window:** Ctrl+F search; Ctrl+I Import; Ctrl+E Export; F1 page help.
- **Tables:** Ctrl-click toggle; Shift-click range; Shift-click heading adds sort; Delete confirms removal on Repository or Edited.
- **Preview:** F Fit; plus/minus zoom; arrows pan; Escape closes.
- **Guide:** Ctrl+F search; Up/Down topic; Ctrl+C copy; Escape close.
- **Folder picker:** Alt+D address bar.

TROUBLESHOOTING

- **Import disabled:** choose a repository/source/device, scan and check eligible rows.
- **No rows:** clear search/filters, choose All Targets and expand session summaries.
- **USB missing:** check its Windows volume, Browse/save the source and refresh devices.
- **Import failure:** read the report; check paths, space and offline cloud availability.
- **Preview unavailable:** check format/decoder limits and required Windows/native codecs.
- **Application missing:** Settings > Export > Application locations; select its GUI executable.
- **Unknown metadata:** inspect Image details; ambiguous values are not inferred.
- **Unknown exposure:** use the Exposure tooltip; EXPTIME or filename gain alone is not total integration.
- **Analysis uncertain:** check solver, site/time and camera/processing metadata.
- **Windows policy block:** inspect signing status and Windows Security; managed policies may need publisher approval.

Setup log: %TEMP%\AstroArchive-setup-error.txt.
Update log: %LOCALAPPDATA%\AstroArchive\updates\last-error.txt.
Report the version and exact error: https://github.com/arijguest/AstroArchive/issues.

FRAME TYPES AND GLOSSARY

- **Light / sub:** one acquisition exposure.
- **Stack:** combined/registered result, separate from its source subs.
- **Dark / Flat / Bias:** calibration exposures for sensor noise, illumination or offset.
- **Master calibration:** combined dark, flat or bias.
- **Starless / Stars only:** edited image layers.
- **Session:** related acquisition group.
- **Device ID:** one physical telescope, separate from its model.
- **Plate solving:** finding an image's sky position.
- **Repository / Edited:** archived originals / working copies and outputs.
